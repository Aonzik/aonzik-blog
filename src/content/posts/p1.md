这是正文的段落占位。中文字体的排版需要关注几个细节：字号与行高的比例、段落的间距、以及标点符号的处理。
正文使用 `Noto Serif SC` 的备选栈，行高设为 1.85，阅读起来比较从容。

段落之间留出约 1.4 倍行高的空隙。这样即便没有首行缩进，段落边界也清晰可辨。
如果需要强调某些词，可以用 **加粗**，或者用 [行内链接](#)，让它在段落里自然浮现。

## 一、正文段落

这是二级标题下的段落。二级标题带一条上方的分隔线，用来划分大的内容区块。
标题的字体是衬线体，与正文形成对比，但字号阶梯不会太跳跃。

这里再放一段，观察两段连续文字在页面上的密度。过密的文字会让人疲劳，
过疏则显得松散。理想的区间大概是每行 30 到 40 个汉字。

## 二、引用与列表

引用块用来引用他人的观点，或者强调一句话：

> 好的排版是看不见的。读者不会注意到它，只会觉得读起来很舒服。
> 当排版开始引人注目的时候，它往往已经出问题了。

无序列表适合罗列并列的项目：

- 列表项一：要点简短清晰，避免整段文字塞进列表；
- 列表项二：项目符号使用强调色，形成视觉引导；
- 列表项三：项与项之间留出少量空隙，便于扫读。

有序列表适合有先后顺序的步骤：

1. 先确定整体基调，纸、墨、朱砂三种意象；
2. 再建立设计 token，颜色、字号、间距全部集中管理；
3. 最后搭建组件，卡片、导航、页脚逐一实现。

## 三、代码与表格

行内代码用浅色底加边框：`const answer = 42;`

代码块则深色铺底，方便长时间阅读：

```
/* 一行 CSS 就能切换整个站点的主题 */
:root {
  --paper: #f6f2ea;
  --ink: #17130e;
  --accent: #a8442a;
}

[data-theme="dark"] {
  --paper: #12100d;
  --ink: #ece5d8;
  --accent: #dd7a53;
}
```

表格适合对比数据：

| 项目 | 说明 | 状态 |
| --- | --- | --- |
| 设计 Token | 颜色、字体、间距变量 | 已完成 |
| 组件样式 | 导航、卡片、页脚等 | 已完成 |
| 正文内容 | 实际文章待补充 | 待定 |
